HDLbits Solutions

A collection of my solutions to HDLbits practice problems, tracking my progress in Verilog HDL as part of my digital design and VLSI coursework.

About

This repository documents my journey through HDLbits — a set of practice exercises for learning Verilog, ranging from basic combinational logic to finite state machines and pipelined circuits. Each commit corresponds to a solved problem, with the goal of building a strong foundation in RTL design.
